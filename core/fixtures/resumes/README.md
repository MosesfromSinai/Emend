# Eval resume fixtures

The brief's build list calls for four teammates' real resumes plus two
deliberately ugly ones. This is a solo build with no real resumes on file
(the `uploads/` PDF the brief references was never pulled into this repo) —
so the four "clean" fixtures below are synthetic, clearly not real people,
built only to stress `structure_resume` across different resume shapes and
formatting conventions. The two `ugly_*` fixtures are deliberately
malformed input.
